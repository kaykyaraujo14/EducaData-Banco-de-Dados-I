# Como finalizar o GitHub e o Classroom — Windows

## Publicação no GitHub

**Situação em 27/11/2026:** o repositório [EducaData-Banco-de-Dados-I](https://github.com/kaykyaraujo14/EducaData-Banco-de-Dados-I) já está público e os materiais estão publicados na branch `main`. As instruções abaixo registram o procedimento de publicação, não uma tarefa pendente. Não crie outro repositório.

1. Entre em https://github.com e acesse a conta da equipe.
2. Abra um repositório existente da equipe ou crie um novo chamado `EducaData-Banco-de-Dados-I` (evite publicar no local errado).
3. Extraia o ZIP da entrega. **Não envie somente o ZIP**: o repositório deve conter `README.md`, `codigo_java/`, `apresentacao/`, `relatorio/`, `modelagem/`, `documentacao/` e `dados_resultados/`.
4. Na página do repositório, use `Add file` → `Upload files` e envie os arquivos/pastas da entrega, mantendo a estrutura. Confira os nomes no preview.
5. Em `Commit changes`, escreva uma mensagem explicativa, por exemplo `Entrega EducaData - Fase 01 e modelagem/implementacao - 2025`.
6. Espere a confirmação e verifique se os materiais aparecem na página. Copie o URL completo do repositório.

O GitHub limita uploads pelo navegador a **25 MiB por arquivo**; arquivos acima de 100 MiB exigem Git LFS ou outro canal, conforme instruções do professor. Não tente enviar arquivos muito grandes sem saber o tamanho. Ver documentação oficial do GitHub.

## Commit final e Classroom

1. Confira se a apresentação em PDF abre, código e README estão acessíveis e link de IA está correto.
2. Faça o **último commit** com uma mensagem clara de revisão final e obtenha o ID do commit.
3. Só após isso, **um integrante** da equipe responde no Classroom com o link do repositório e o que o professor pedir.
4. Confirme que o comentário ou envio ficou visível na publicação indicada pelo professor. O prazo deve ser confirmado na orientação vigente do Classroom, pois o PDF e o checklist registram datas diferentes.

Não afirmar que GitHub ou Classroom foram concluídos sem confirmação real.
